## 1. 定位

v3.1 解决了"我该买什么"（策略模板引导配置）。v3.2 解决"现在市场处于什么状态"。

**核心理念：** 帮助价值投资者感知市场环境，知道"什么便宜、什么合理、什么贵了"，为卫星仓提供概念热度参考。

## 2. 页面结构

```
市场脉搏 /market-pulse

┌─────────────────────────────────────┐
│  估值水位热力图（默认主体）           │

└─────────────────────────────────────┘
```

## 3. 功能清单

### 3.1 估值水位热力图

- 展示 A 股主要行业（申万一级行业或东财行业分类）的当前 PE/PB
- 每行：行业名称、当前 PE、PE 历史分位（近 5 年）、颜色标注
- 颜色编码：分位 < 20%（绿/低估）、20-80%（黄/合理）、> 80%（红/高估）
- 点击行业展开：PE 趋势图（历史曲线 + 当前值标注）、成分股列表（可选）

### 3.2 概念板块热度榜

- 展示东财概念板块的近期表现
- 按涨跌幅或换手率排序
- "价值过滤"开关：仅显示有基本面支撑的（ROE > 0 的成分股占比 > 50%）
- 每行：概念名称、涨跌幅、领涨股、资金流向方向

### 3.3 资金流向概览

- 北向资金净流入/流出（日/周）
- 主力资金行业流向（净流入前 5 + 净流出前 5）

### 3.4 持仓关联提醒

- 基于用户持仓中价值仓的行业分布，匹配估值水位数据
- 当某个持仓行业 PE 分位 < 20%（低估）或 > 80%（高估）时展示提醒卡片
- 不自动推送（v3.1 无推送基础设施），仅在页面内展示

## 4. 数据源

| 数据类型 | AKShare 接口 | 更新频率 |
|---------|-------------|---------|
| 行业 PE/PB 分位 | `stock_board_industry_pe_em` / 东方财富行业市盈率 | 每日 |
| 概念板块行情 | `stock_board_concept_name_em` + `stock_board_concept_hist_em` | 每日 |
| 概念成分股 | `stock_board_concept_cons_em` | 按需 |
| 北向资金 | `stock_hsgt_north_net_flow_in_em` | 每日 |
| 行业资金流向 | `stock_sector_fund_flow_rank` | 每日 |

## 5. 数据模型

沿用 v3 设计文档中定义的 `MarketIndicator` 缓存模型：

```prisma
model MarketIndicator {
  id            String   @id @default(uuid())
  market        String   @default("A_STOCK")
  indicatorType String   // 'valuation' | 'fund_flow' | 'concept'
  category      String   // 行业/概念名称
  data          Json     // 指标数据
  fetchedAt     DateTime @default(now())

  @@index([market, indicatorType])
  @@index([fetchedAt])
}
```

## 6. API 设计

```
GET  /api/market-data/valuation    估值水位数据
GET  /api/market-data/concepts     概念板块热度（?filter=fundamental）
GET  /api/market-data/fund-flow    资金流向概览
GET  /api/market-data/refresh      手动刷新所有市场数据
```

---

## 7. 技术方案

- AKShare 通过 `child_process.spawn` 调用 Python 脚本获取 JSON
- 一层轻量 Python 脚本（`server/src/lib/akshare/` 目录），每个脚本负责一个数据维度
- 结果写入 `MarketIndicator` 表缓存
- 后端定时刷新（每小时），前端手动刷新按钮
- 失败降级：返回最近一次缓存数据

Python 依赖：`pip install akshare`，脚本约 20-30 行每个。
