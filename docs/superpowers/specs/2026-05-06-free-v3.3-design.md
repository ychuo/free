## 1. 定位

v3.2 告诉你"正在发生什么"。v3.3 帮你回答"这意味着什么、我该怎么做、以及我做得对不对"。

**核心原则：引擎 + 训练双线并行**

- **信号引擎**（原 v3.3）：ValueScore + HotScore 双轨评分，主动发现机会
- **判断力训练**（新增）：因子拆解 + 历史回测参考 + 信号复盘 + 决策日记

## 2. 信号评分引擎

### 2.1 ValueScore（价值轨道）

```
ValueScore = 0.35 × 估值安全边际（PE/PB 分位取反）
           + 0.30 × 生意质量（ROE 稳定性 + 毛利率水平）
           + 0.20 × 护城河信号（行业地位 + 现金流质量）
           + 0.15 × 催化剂（景气改善 + 政策利好）
```

输出 0-100，>70 进入价值发现榜，标注"低估/合理/高估"区间。

### 2.2 HotScore（动量轨道）

```
HotScore = 0.30 × 概念热度（提及增速 + 搜索量变化）
         + 0.30 × 资金信号（成交量异常 + 主力净流入）
         + 0.20 × 趋势强度（连续上涨天数 + 突破均线）
         + 0.20 × 情绪信号（新闻正向率 + 讨论活跃度）
```

输出 0-100，>70 进入热点信号榜，标注提前量标签（早期/中期/末期）。

### 2.3 因子拆解

每个信号不只是一个分数，展示各因子贡献：

```
ValueScore 78 — 低估区间
├── 估值安全边际 35% × 95 = +33.3  ← PE 处于近5年8%分位
├── 生意质量     30% × 72 = +21.6  ← ROE 连续3年>15%, 毛利率稳定
├── 护城河信号   20% × 60 = +12.0  ← 行业前三, FCF/净利润>0.8
└── 催化剂       15% × 73 = +10.9  ← 景气指标改善, 政策利好
                 Total  =  77.8
```

### 2.4 提前量判断

- **早期**：信号刚出现，资金和舆情刚开始升温，风险高收益潜力大
- **中期**：趋势已确认，多个信号源交叉验证
- **末期**：热度顶峰或开始衰退，追高风险大

判断依据：提及增速斜率、资金流入加速度、估值分位变化。

## 3. 判断力训练系统

### 3.1 历史回测参考

每个信号附带简化的历史参考：

> "近 5 年内，类似信号（PE 分位 < 15% + ROE > 15% + 主力净流入）出现后：
> 3 个月上涨概率 68%，中位数回报 +8.2%
> 6 个月上涨概率 73%，中位数回报 +14.5%"

数据来源：同花顺行业历史数据 + 估值分位回溯。

### 3.2 信号复盘

记录每次信号快照（触发时的分数、各因子值、市场环境），后续自动追踪结果：

| 信号日期 | 行业 | 得分 | 触发时价格 | 当前价格 | 涨幅 | 结果 |
|---------|------|------|----------|---------|------|------|
| 2026-05-06 | 银行 | 82 | 3560 | 3620 | +1.7% | 进行中 |
| 2026-04-15 | 白酒 | 75 | 12800 | 12550 | -2.0% | 未确认 |

复盘页可以按时间、行业、结果筛选，帮助用户回头看"哪些信号我把握住了、哪些错过了"。

### 3.3 决策日记

信号详情页有一个文本框："**你的判断**"。

用户可以记录：
- 为什么决定跟/不跟这个信号
- 看到了什么反证
- 当时的市场情绪

这些笔记和信号结果绑定，事后回顾时可以对照"我当时怎么想的"和"实际发生了什么"，这是建立判断力的核心机制。

## 5. 数据模型

### 5.1 新增模型

```prisma
model SignalRecord {
  id          String   @id @default(uuid())
  market      String   @default("A_STOCK")
  track       String   // 'value' | 'momentum'
  targetCode  String   // 行业/概念代码
  targetName  String   // 显示名称
  score       Float    // ValueScore 或 HotScore
  factors     Json     // 各因子得分 + 原始值
  stage       String   // 'early' | 'mid' | 'late'
  backtest    Json?    // 历史回测参考数据
  triggeredAt DateTime @default(now())

  @@index([market, track])
  @@index([triggeredAt])
}

model SignalJournal {
  id        String   @id @default(uuid())
  userId    String   @default("default")
  signalId  String
  note      String   // 用户判断笔记
  action    String   // 'followed' | 'ignored' | 'watched'
  createdAt DateTime @default(now())

  @@index([userId])
  @@index([signalId])
}
```

### 5.2 评分计算

信号评分通过 `SignalCalculator` 类实现，每小时运行，读取 MarketIndicator 缓存数据 + 用户持仓数据，计算 ValueScore/HotScore，写入 SignalRecord 表。计算为纯 TypeScript 逻辑（不依赖 Python）。

## 8. 数据来源

评分引擎的数据基础是 v3.2 已接入的 MarketIndicator 缓存表：

| 因子 | 数据来源 | 状态 |
|------|---------|------|
| 估值安全边际 | 暂无 PE/PB 分位数据 | ⚠️ 需要补充 |
| 生意质量 (ROE) | MarketIndicator 行业数据 | ⚠️ 需要补充 |
| 资金信号 | stock_market_fund_flow（已有） | ✅ |
| 概念热度 | stock_board_concept_summary_ths（已有） | ✅ |
| 趋势强度 | 行业涨跌幅（已有） | ✅ |
| 情绪信号 | 暂无明确来源 | ⚠️ v3.3 暂用涨跌幅代理 |

**关键缺口：PE/PB 分位数据。** 同花顺不直接提供，需要从行业历史数据自行计算。v3.3 会从同花顺行业指数历史数据（`stock_board_industry_index_ths`）中提取 PE/价格序列，计算当前值在历史中的分位。

## 9. v3.3 不做的

- 不做实时推送（v3.3 页面内展示 + 浏览器通知即可）
- 不做社交情绪 NLP（数据源不可用）
- 不做自动化交易执行
- 不做 Monte Carlo 模拟（v4）
- 不做多策略对比（v4）
