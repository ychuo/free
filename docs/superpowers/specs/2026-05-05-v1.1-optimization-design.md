# v1.1 全面优化设计

## 范围

修复全部 17 个已识别问题，涵盖 6 个模块，目标完成后进入 v2 阶段。

## 模块一：基础架构（错误处理 + Toast + Loading + 类型安全）

### 错误处理

5 个 hooks（`useAssets`, `useLiabilities`, `useNetWorth`, `useFireProfile`, `useAllocation`）的 API 调用加 try/catch，错误通过 toast 通知用户。api client 的错误消息已为中文，直接透传。

### Toast 通知

引入 `sonner`（shadcn/ui 风格），`App.tsx` 挂载 `<Toaster>`，Kami 主题适配。成功操作 toast："已添加资产" / "已更新" / "已删除"。

### Loading 骨架屏

首次加载：资产列表 3 行占位、净值卡片 3 个矩形、图表区圆形占位。后续操作 loading 通过按钮 disabled + spinner 体现，不阻塞已渲染内容。

### 服务端类型安全

6 个路由文件统一在 route options 中声明 `schema: { body: ... }`（Fastify 原生 JSON Schema 校验），shared 包导出 schema 定义。非法请求 Fastify 自动返回 400。

### 涉及文件

- `web/src/hooks/*.ts` — try/catch + toast（5 个文件）
- `web/src/App.tsx` — `<Toaster>`
- `web/src/pages/*.tsx` — 骨架屏（3 个页面）
- `web/src/components/ui/sonner.tsx` — 新增 shadcn/sonner
- `server/src/routes/*.ts` — schema validation（6 个文件）
- `shared/src/types.ts` — JSON Schema 定义

## 模块三：后端改进（快照日期 + 零值目标清理 + 计算收敛）

### 可指定快照日期

`POST /api/snapshots` 接受可选 `snapshotDate`（ISO 字符串）。前端"记录快照"按钮旁加日期选择器。

### 零值分配目标清理

`PUT /allocation-targets` 改为先删后建：删除当前用户全部 targets，再批量插入非零比例目标。零比例不再留库。

### 计算函数收敛

新建 `server/src/lib/calculations.ts`，将净值和分类汇总抽成纯函数，供 `netWorth`、`fireProfile`、`snapshots`、`allocation` 四路由复用。

## 模块五：数据管理（导入导出 + 批量操作）

### 导出

概览页"导出数据"按钮，生成 JSON 文件下载，包含全部 assets / liabilities / fireProfile / allocationTargets / snapshots。纯前端从 state 取数据。

### 导入

"导入数据"按钮，文件选择器（`.json`），解析后逐条调用 API 创建。导入前弹确认框说明：**追加而非覆盖**，建议先清除现有数据。客户端校验顶层 key 格式。

### 批量删除资产

`AssetList` 每行加 checkbox，顶部"选择模式"工具栏显示选中数量 + 批量删除按钮。完成后 toast 告知删除 N 条。

- API: 新增 `DELETE /api/assets` 批量删除端点（body: `{ ids: string[] }`）
- Hook: `useAssets` 新增 `removeMany` 方法

### 涉及文件

- `web/src/components/AssetList.tsx` — 批量选择 + 删除
- `web/src/hooks/useAssets.ts` — `removeMany`
- `web/src/lib/api.ts` — 批量删除 API
- `server/src/routes/assets.ts` — `DELETE /` 批量删除端点
- `web/src/pages/AssetOverview.tsx` — 导出/导入按钮 + 处理逻辑
- `shared/src/types.ts` — `ExportData` 类型（含 assets / liabilities / fireProfile / allocationTargets / snapshots 五个字段）

## 模块六：多币种 + 手动汇率

### 表单

`AssetForm` 加币种下拉（CNY / USD / HKD / EUR / JPY / GBP），默认 CNY。选非 CNY 时展开汇率字段（1 该币种 = ? CNY），手动填写。

### 服务端计算

`calculations.ts` 聚合时，非 CNY 资产按 `totalValue * exchangeRate` 换算为 CNY 后再计入 totalAssets 和 categoryBreakdown。汇率存储在 Asset 的 `properties` JSON 字段（key: `exchangeRate`），不改 Prisma schema。

### 前端

`AssetList` 中非 CNY 资产在原币金额下方显示换算后 CNY 金额（灰色小字）。图表和再平衡分析组件收到的已是换算后 CNY 值，无需改动。

### 涉及文件

- `web/src/components/AssetForm.tsx` — 币种 + 汇率
- `server/src/lib/calculations.ts` — 汇率换算
- `web/src/components/AssetList.tsx` — 显示换算值
- `shared/src/types.ts` — `SUPPORTED_CURRENCIES` 常量
